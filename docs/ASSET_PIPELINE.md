# Asset Pipeline

The game uses no downloaded art. Everything is generated by the project's own code.

## Meshes

These are generated at runtime by `scripts/world/generators/*` and `CreatureBuilder`.

1. Add or tune parameters. For example, `MushroomParams` is an editor-friendly `Resource`.
2. Preview generators with `tools/dev/preview_generators.tscn`, which renders a lineup and saves PNGs.
3. Review the full region with `tools/dev/capture_tour.tscn`, which renders twelve viewpoints and logs draw calls and primitives.

Conventions:

- Godot front faces are clockwise. Use the `MeshKit` helpers so faces end up correct.
- Vertex color = albedo. **Vertex alpha = emission mask.**
- Per-object budget: small props under ~300 vertices (`detail` ≈ 0.3), giant landmarks 1–3k.

## Materials and shaders

| File | Purpose |
|---|---|
| `shaders/organic.gdshader` | Toon light with a rim, emission from vertex alpha, sway, breathing |
| `ground.gdshader` | Painterly terrain with pulsing mycelium veins |
| `water.gdshader` | Lake, waterfalls and the sky river |
| `crystal.gdshader` | Faceted iridescent crystals |
| `dream_sky.gdshader` | Sky |
| `glow_additive.gdshader` | Additive glow for beams and VFX |
| `rune_circle.gdshader` | Arena rune circle |
| `transition.gdshader` | Screen transitions |
| `title_shimmer.gdshader` | Title text |
| `chaos_warp.gdshader` | Chaos-spell screen warp |

`MaterialLib` caches material variants by intent (`mushroom()`, `foliage()`, `stone()` …).

## Audio

`tools/generate_audio.py` uses numpy to synthesize every WAV in `assets/audio/` with additive and FM synthesis, Karplus-Strong plucks, filtered noise and convolution reverb. Music and ambience loops are folded at their tail so they loop seamlessly. Rerun the script after editing it; Godot re-imports the files automatically.

## Data

`tools/build_content.gd` writes every `.tres` under `resources/`. Edit the definitions there and rerun:

```bash
godot --headless --script res://tools/build_content.gd
```

Dialogue, skill trees and shops are plain JSON.

## Fonts

Inter (OFL 1.1) and Caladea (OFL 1.1) were copied from the system font packages. Their license texts are in `assets/fonts/`.
